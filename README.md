# ClaudeCode-WEB-sekkei-agent

既存 Web サイトを調査し、Web サイト設計書（現状構成の整理と再構築・改修時の設計仕様）を作成するためのリポジトリ。

## 設計書一覧

| 対象サイト | ディレクトリ | 作成日 |
|---|---|---|
| MUTO coffee roastery（https://muto-coffee.com/） | [docs/muto-coffee/](docs/muto-coffee/README.md) | 2026-09-11 |

## 設計書の構成

各設計書は次の章立てで作成する。

| 章 | 内容 |
|---|---|
| 01 | 概要・要件定義（事業情報、目的と KPI、ターゲット、機能要件、非機能要件） |
| 02 | サイト構成・URL 設計（システム構成、サイトマップ、ページ一覧、URL 規約、ナビゲーション） |
| 03 | 画面設計（共通レイアウト、各画面のワイヤーフレームと要素定義、レスポンシブ） |
| 04 | 機能・データ設計（CMS／EC 機能、フロー、データ項目定義、メール、外部連携） |
| 05 | デザイン・非機能要件（トーン＆マナー、カラー、タイポグラフィ、SEO、アクセシビリティ、性能、セキュリティ） |
| 06 | 運用・改善提案（運用体制、更新フロー、課題と改善提案、ロードマップ、検収基準） |
| 99 | 調査ログ・未確認事項（ソース一覧、確認状態、実機確認チェックリスト） |

記述の確度は **【確認済】／【推定】／【要確認】／【提案】** で明示する。
