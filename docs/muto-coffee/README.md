## 記法

- **【確認済】** … 公開ページの内容または複数の第三者メディアで裏付けが取れた事項
- **【推定】** … URL構造や一般的なCMSの仕様から合理的に推定した事項
- **【要確認】** … 本設計書の作成環境からは検証できず、実機（ブラウザ）での確認が必要な事項
- **【提案】** … 現行サイトには存在しない、または変更を推奨する設計

## 前提と制約

本設計書の作成環境からは対象サイトへの直接アクセス（HTML取得・スクリーンショット）がネットワークポリシーにより許可されなかった。
そのため、ページの実際のレイアウト・配色・画像・スクリプトは未確認であり、画面設計（03章）の現状記述は検索エンジンにインデックスされたテキストと URL 構造からの推定を含む。
実装着手前に [99_research_log.md](99_research_log.md) の「実機確認チェックリスト」を消化すること。
