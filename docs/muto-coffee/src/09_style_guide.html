使わないもの

店内にこれがあるか、を判断基準にします
  • スライダー・カルーセル（速度を損ない、伝えたいことがぼやける）
  • 自動再生の動画・パララックス
  • 点滅するバナー・アニメーションするアイコン
  • 影を多用したカード（ふわふわした印象になる）
  • 鮮やかな差し色を複数（色数は絞る）
  • 細すぎる明朝体の本文
  • ダークモード（紙のような明るい地色がブランドの核。color-scheme: light を明示）
