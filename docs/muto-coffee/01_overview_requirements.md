### 1.2 本書の目的

1. 現行サイトの構成（ページ、URL、機能、データ）を体系的に文書化し、関係者間の共通理解を作る。
2. 再構築・改修時に、そのまま実装仕様として利用できる粒度の設計を提供する。
3. 現状の課題を洗い出し、改善の優先順位を示す（06章）。

### 1.3 サイトの現状構成（サマリ）

現行サイトは、性格の異なる2つのシステムで構成されている。【推定：URL構造より】

| 領域 | 役割 | 基盤 | 根拠 |
|---|---|---|---|
| 店舗サイト（`muto-coffee.com/`） | 店舗案内、メニュー、News（お知らせ・新入荷） | WordPress 【推定】 | 投稿タイトルがそのまま日本語スラッグになった固定リンク（`/年末・年始-営業日時のお知らせ-2/` 等）、`/news/` アーカイブ、ページタイトルの `\| サイト名` 形式 |
| オンラインショップ（`/shop/`） | コーヒー豆の通信販売 | EC-CUBE 【推定】 | `/shop/products/list`、`/shop/products/detail/{id}`、`/shop/help/about`、`/shop/help/tradelaw` という EC-CUBE 3/4 系標準ルーティング、「TOPページ」「当サイトについて」という既定ページ名 |

### 2.1 ブランドの特徴（コンテンツの核）

- 元CMプロデューサーのオーナーが堀口珈琲で修業ののち開業、というストーリー性。
- トレーサビリティの明確なスペシャルティコーヒーを、店頭の GIESEN 焙煎機で毎日焙煎。
- ハンドドリップで浅煎り〜中煎りを中心に提供、深煎りブレンドも用意。
- 自家製スイーツ（ベイクドチーズケーキ、ガトーショコラ、季節のパウンドケーキ）。
- 木とレザーを基調とした落ち着いた店内（第三者メディアより）。

## 3. サイトの目的と KPI

| 目的 | 指標（KPI） | 目標の考え方 |
|---|---|---|
| 来店促進 | 店舗情報ページの閲覧数、電話タップ数、地図リンクのクリック数 | 営業時間・定休日を迷わず確認できること |
| オンライン販売 | 商品詳細→カート投入率、購入完了数、会員登録数 | 店頭で購入した豆をリピート購入する導線 |
| 認知・信頼 | News 更新頻度、SNS への送客数、指名検索数 | 焙煎のこだわりとオーナーのストーリーを伝える |
| 運用負荷の低減 | 更新にかかる時間、更新者数 | 店主1名でも News と商品を即日更新できる |

## 4. ターゲットユーザー

| ペルソナ | 状況 | 主な行動 | 必要な情報 |
|---|---|---|---|
| A. 近隣住民・勤務者 | 中野駅周辺で休憩したい | スマホで「中野 コーヒー」検索→営業中か確認→来店 | 営業時間、定休日、地図、混雑・席数 |
| B. コーヒー愛好家 | 焙煎の質で店を選ぶ | Instagram や記事から来訪→豆ラインナップを吟味 | 焙煎度、精製方法、味わい、焙煎機、オーナーの経歴 |
| C. リピーター（遠方） | 店頭で買った豆を再購入 | ショップに直行→ログイン→購入 | 在庫、価格、送料、発送日 |
| D. ギフト購入者 | 贈答用に豆を探す | ギフト包装の可否と配送先指定 | ギフト対応、支払方法、納期 |

| F-04 | News をカテゴリ分類し、種類ごとに絞り込める | 推奨 | 要確認 |
| F-05 | オンラインショップへの導線（グローバルナビ・トップ・フッター）を設ける | 必須 | あり |
| F-06 | 地図（Google マップ埋め込み等）と経路案内リンクを表示する | 推奨 | 要確認 |
| F-07 | 店舗・焙煎のこだわりを紹介する About セクション／ページ | 推奨 | 要確認 |
| F-08 | SNS（Instagram／Facebook）へのリンクを表示する | 推奨 | 要確認 |

## 6. 非機能要件

| 分類 | 要件 |
|---|---|
| 対応デバイス | スマートフォン優先（モバイルファースト）、タブレット、PC |
| 対応ブラウザ | 各 OS 最新版の Chrome、Safari、Edge、Firefox。iOS Safari は直近2メジャーバージョン |
| 表示性能 | LCP 2.5秒以内、CLS 0.1以下（モバイル 4G 相当）。画像は WebP＋遅延読み込み |
| 可用性 | 年間稼働率 99.5% 以上（共用レンタルサーバー水準） |
| セキュリティ | 全ページ HTTPS、管理画面の IP 制限または二要素認証、CMS・EC の定期アップデート、決済情報は非保持（決済代行トークン方式） |
| アクセシビリティ | WCAG 2.1 AA 相当（コントラスト比 4.5:1、キーボード操作、代替テキスト） |
| SEO | ページごとの title／description、正規 URL の統一、構造化データ（CafeOrCoffeeShop、Product） |
| 多言語 | 日本語のみ（将来の英語対応を妨げない構造にする） |
| 運用 | 店主が管理画面から News・商品・営業時間を更新できる。専門知識不要 |
| バックアップ | DB・ファイルを日次で自動バックアップ、30日保持 |
| 法令 | 特定商取引法、個人情報保護法、景品表示法（価格表示は税込） |
