# 06. 運用・改善提案

## 1. 運用体制

| 役割 | 担当 | 業務 |
|---|---|---|
| コンテンツ更新 | 店主（武藤氏） | News 投稿、営業時間・臨時休業の更新、商品登録・在庫更新、受注処理 |
| 技術保守 | 制作会社または担当エンジニア | CMS・EC の更新、バックアップ確認、障害対応、ドメイン・サーバー更新 |
| 決済・配送 | 店主 | 発送、伝票番号入力、返品対応 |

## 2. 更新フロー

### 2.1 News 投稿

1. WordPress 管理画面 → 投稿 → 新規追加
2. タイトル、本文、カテゴリ（お知らせ／新入荷／セール／スイーツ）、アイキャッチ
3. 新入荷の場合は「関連商品 URL」にショップの商品詳細 URL を入力
4. 臨時休業の場合は「サイト設定 → 臨時休業日」にも日付を追加（営業状況表示に反映）
5. 公開。Instagram にも同内容を投稿

### 2.2 商品の入替

1. EC-CUBE 管理画面 → 商品管理 → 新規登録
2. 商品名、カテゴリ、税込価格、内容量、精製方法、焙煎度、味わい、画像
3. 挽き方の規格を割当（提案採用時）
4. 公開。終売品は「非公開」にし削除しない（注文履歴・URL 維持のため）
5. 店舗サイトの News に「新入荷」記事を投稿（2.1）

### 2.3 受注処理

1. 注文受付メールを確認（shop@）
2. 焙煎・梱包（注文確認後3営業日以内）
3. ヤマト運輸で発送、伝票番号を受注に入力し「発送済」に変更 → 発送完了メール自動送信

### 2.4 定期メンテナンス

| 頻度 | 作業 |
|---|---|
| 日次 | 自動バックアップの成否確認（通知メール） |
| 週次 | 受注・問い合わせの未処理確認、スパムコメント削除 |
| 月次 | WordPress／EC-CUBE／プラグイン更新（ステージングで検証後）、Search Console のエラー確認 |
| 年次 | ドメイン・SSL・サーバー契約更新、特商法表記の見直し、年末年始の営業案内投稿 |

## 3. 現状の課題と改善提案

| No. | 課題（現状） | 影響 | 提案 | 優先度 |
|---|---|---|---|---|
| I-01 | サイト名の綴りが「roastery」と「roastary」で混在（News 側タイトル末尾） | ブランド表記の不統一、検索結果の見栄え | WordPress 一般設定のサイトタイトルを「MUTO coffee roastery」に修正 | 高・即日 |
| I-02 | ショップ URL が `www` あり／なしの両方でインデックスされている | 重複コンテンツ、評価分散 | 正規ホストを決め 301 リダイレクト、canonical 出力 | 高 |
| I-03 | News 詳細 URL がタイトル由来の日本語スラッグで `/news/` 配下にない | 共有時に長大なエンコード URL、構造が不明瞭 | 新規記事から英数字スラッグ＋`/news/` 配下に変更。旧 URL は 301 | 中 |
| I-04 | News のカテゴリ分類が確認できない | 営業案内と新入荷が混在し、探しにくい | 4カテゴリ導入、一覧にタブ | 中 |
| I-05 | 臨時休業・年末年始が News 記事のみで、トップの営業案内と二重管理 | 更新漏れリスク | 営業状況の自動表示＋お知らせバー | 中 |
| I-06 | 店舗サイトとショップが別システムでデザイン・ヘッダーが乖離する可能性 | 回遊率低下、ブランド一貫性 | 共通 CSS 変数とヘッダー／フッターの共通化 | 中 |
| I-07 | 商品詳細の情報が精製・焙煎度・味わいの3項目 | 愛好家（ペルソナ B）の判断材料が不足 | 地域・品種・標高・生産者を任意項目で追加 | 中 |
| I-08 | 挽き方の選択可否が不明 | 器具を持たない購入者の離脱 | 規格「挽き方」を追加 | 中 |
| I-09 | プライバシーポリシー・ご利用ガイド・送料表がインデックスに見当たらない | 法令・信頼面の不安、購入前の離脱 | ヘルプページを整備し、フッターから常時リンク | 高 |
| I-10 | SNS リンク（Instagram／Facebook）の設置状況が不明 | 送客・認知機会の損失 | ヘッダー・フッター・トップに設置。公式は `@mutocoffeeroastery` | 低 |
| I-11 | 構造化データ（店舗・商品）の有無が不明 | 検索結果でのリッチ表示機会の損失 | 05章 6.2 の JSON-LD を実装 | 低 |
| I-12 | EC-CUBE のバージョンが不明。3 系の場合はサポート終了 | セキュリティリスク | バージョン確認のうえ 4 系最新へ移行計画 | 高（確認は即日） |
| I-13 | 店舗サイト側にお問い合わせ手段（フォーム）があるか不明 | 電話以外の問い合わせ手段不足 | ショップの `/shop/contact` へ統一導線 | 低 |
| I-14 | 席数・Wi-Fi・電源など来店前に知りたい設備情報が公式に見当たらない | 第三者サイト依存 | Access セクションに「店内設備」を追記 | 低 |
