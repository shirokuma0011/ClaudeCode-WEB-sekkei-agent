# Webサイト制作入力

【事業内容】
駅前の内科・小児科クリニック。一般内科診療、予防接種、健康診断を行い、地域のかかりつけ医として日常的な体調不良の相談に対応する。

【事業名・サービス名】
みなと内科・小児科クリニック

【サイトの目的】
初診患者の来院促進、診療内容の周知、Web予約の利用促進

【ターゲット】
近隣に住む子育て世帯、通勤で駅を使う20〜50代、高齢の家族を持つ人

【希望する雰囲気】
清潔、安心、親しみやすい、明るい、落ち着き

【問い合わせ・CV方法】
Web予約（外部予約システム。URL未定）、電話

【写真素材】
なし。画像生成プロンプト10件を作成する。生成画像は院内や医師の実写として扱わない

【実装前提】
HTML/CSS/JavaScript

【注意事項】
医療広告ガイドラインに従い、治療効果の保証や体験談を掲載しない。診療時間、休診日、費用、対応する予防接種の種類は開院後に確定するため要確認とする
