## 1. 設計方針

| 原則 | 内容 |
|---|---|
| **目的ベースで分ける** | 「会社の事業部」ではなく「訪問者がやりたいこと」で第1階層を切る |
| **URLは内容を表す** | 英小文字・ハイフン区切り・ヘボン式。日付や連番を使わない |
| **3クリック以内** | トップから任意の詳細ページまで最大3クリック |
| **重複を統合** | 同名・類似ページは1本に統合し、評価を集約する |
| **一覧と詳細を分ける** | 物件・事例は「一覧（絞込み可）」＋「詳細（1件1ページ）」の2層構造 |

## 2. ブランド階層の整理（課題A-4への対応）

サイト上での呼称を以下に固定します。

```
株式会社協進建設                      ← 事業主体（法人格）。会社情報・許可番号はここ
 └ 協進住宅                          ← 住宅事業の呼称（統合済みのため部門名として扱う）
    ├ ステイブルハウス                ← 注文住宅の商品ブランド（性能訴求の核）
    ├ 分譲住宅 / 売地                 ← 自社分譲・仲介
    └ リノベーション                  ← リフォーム事業
```

- サイトの**発行者名は「株式会社協進建設」に統一**（構造化データ・フッター・著作権表示）。
- 「協進住宅」はナビゲーションやtitleには出さず、会社情報ページ内で
  「協進住宅は当社の住宅事業部門です（20XX年に統合）」と1文で説明。
- 「ステイブルハウス」は**注文住宅の商品名**としてのみ使用。
  現行の「ステイブルハウス」「ステイブルハウス2」は1ページに統合する。

### 3.1 第1階層の絞り込み理由

グローバルナビは **6項目** に固定します（認知負荷の観点から7±2の下限側）。

```
注文住宅 ｜ 分譲・土地 ｜ リフォーム ｜ 施工事例 ｜ 会社情報 ｜ [お問い合わせ]
```

- 「駐車場」は単独では検索需要が小さく、`/property/` 配下に格納。
- 「お知らせ」はグローバルナビに入れず、トップと フッターから導線を確保。
- 「お問い合わせ」はナビ内でボタン化し、常時視認できるようにする。

## 4. URL設計ルール

| ルール | 内容 | 例 |
|---|---|---|
| 文字種 | 英小文字・数字・ハイフンのみ | `custom-home` |
| ローマ字 | **ヘボン式**（訓令式の `shintiku`/`uriti` は廃止） | `shinchiku` ではなく意味のある英語 `new-house` |
| 言語 | カテゴリは英語、固有名詞のみローマ字可 | `/works/`, `/property/` |
| 末尾 | ディレクトリ形式（末尾スラッシュ）で統一 | `/about/company/` |
| 階層 | 最大3階層まで | `/custom-home/plans/{slug}/` |
| ID | 物件・事例は `{連番}-{短いスラッグ}` | `/property/1042-yagicho-newhouse/` |
| 日付 | **URLに入れない**（リライトしても陳腐化しないため） | ✗ `/news/2026/09/11/` |
| 正規化 | `https://www.` に統一。非wwwとhttpは301 | |

### 4.1 なぜIDとスラッグの併用か

- **IDのみ**（`/property/1042/`）→ 内容が分からない
- **スラッグのみ**（`/property/yagicho-newhouse/`）→ 同町名の別物件で衝突する
- **ID＋スラッグ** → 一意性と可読性を両立。スラッグ変更時もIDで解決でき、リンク切れが起きない

## 5. 旧URL → 新URL リダイレクト対応表

**全件301リダイレクト必須**です。これを怠ると、これまで積み上げた検索評価が失われます。

| 旧URL | 新URL | 備考 |
|---|---|---|
| `/` | `/` | 変更なし |
| `/page1` | **要確認** → 内容に応じて割当 | 実機で内容確認のうえ決定 |
| `/page6` | `/about/company/` | 会社概要 |
| `/forsale` | `/property/` | 物件情報 |
| `/shintiku` | `/property/new-house/` | 新築分譲住宅 |
| `/uriti` | `/property/land/` | 売地・建築条件付売地 |
| `/20190518144118` | `/property/?featured=1` | おすすめ物件 → 一覧のおすすめ絞込みへ |
| `/20190525182824` | `/custom-home/plans/` | PLAN集 |
| `/20210518174847` | `/custom-home/` | ステイブルハウス（統合先） |
| `/20210709172902` | `/custom-home/` | ステイブルハウス2（**統合**） |
| `/20210718095501` | `/custom-home/zeh-bels/` | BELS評価 |
| `/20181215134240` | `/works/?category=exterior` | 施工例-外観・外構- |
| `/20190622160130` | `/renovation/` | Renovation（統合先） |
| `/20210909110938` | `/renovation/` | Renovation（**統合**） |
| `/20230307104154` | `/property/parking/` | 駐車場のご案内 |
| `/20230922152716` | `/works/` | case |

> **未確認URLへの備え**: 上表は検索インデックスから確認できた16件です。
> 実際にはこれ以外のページが存在する可能性があります。移行前に必ず
> 「既存サイトの全URL棚卸し」（`tools/fetch-site-assets.sh` が同時に生成）を行い、
> **1件も取りこぼさずリダイレクト表に反映**してください。
> 加えて、`/*` を受ける**カスタム404ページ**を用意し、
> 主要導線（トップ・物件一覧・問い合わせ）へ誘導します。

### 5.1 ページ統合時の注意

`ステイブルハウス` ＋ `ステイブルハウス2` → `/custom-home/` のように統合する場合、
**両方のページの内容を新ページに漏れなく載せてから**リダイレクトします。
内容のないページへリダイレクトすると「ソフト404」と判定され、評価が引き継がれません。

## 6. 目的別ユーザー導線

図版: `assets/diagrams/user-journey.svg`

### P1: 土地から探す一次取得層
```
トップ
 → [はじめての方へ] または [注文住宅]
 → /custom-home/            ブランドと世界観を知る
 → /custom-home/performance/ 性能で納得する（光熱費の数字）
 → /works/?category=new      実例を見る（価格帯つき）
 → /custom-home/price/       総額の目安を掴む
 → /contact/document/        資料請求（心理的ハードルが最も低いCV）
```
> **設計上の要点**: 各ページ下部に「次に見るべきページ」を1〜2件だけ提示し、
> 迷わせない。CTAは常に「資料請求（軽い）」と「来場予約（重い）」の2段階を並置。

### P2: 建売・土地を探す層
```
トップ → /property/ → 絞込み（エリア・価格） → /property/{id}/ → [この物件について問い合わせる]
                                                    ↓
                                          [この家の性能を見る] → /custom-home/performance/
```
> **設計上の要点**: 物件詳細から**自社の建築品質へ橋渡し**する内部リンクを必ず置く。
> 他社物件と並べて比較されたときの決定打になる。

### P3: リフォーム層
```
トップ → /renovation/ → /renovation/price/（相場を知る） → /works/?category=reno（Before/After）
       → /contact/renovation/
```
> **設計上の要点**: 訪問販売との差別化のため、`/about/company/` への導線（創業年・許可番号）を
> リフォームページ内に明示する。

## 7. 各ページの役割定義

| ページ | 目的 | 主要CTA | 成功指標 |
|---|---|---|---|
| トップ | 事業の全体像を3秒で伝え、目的別に振り分ける | 各カテゴリへの遷移 | 直帰率 < 45% |
| /custom-home/ | ブランド理解と性能への信頼 | 資料請求 | 下層への遷移率 > 50% |
| /custom-home/performance/ | 技術的な納得 | 資料請求 | 滞在 > 120秒 |
| /property/ | 条件に合う物件を見つけさせる | 詳細への遷移 | 絞込み利用率 |
| /property/{id}/ | 個別物件の検討を進める | 物件問い合わせ | CVR > 3% |
| /works/ | 実力の証明 | 事例詳細 → 相談 | 回遊 > 2.5PV |
| /renovation/ | 相場の不安を解消 | リフォーム相談 | CVR > 2% |
| /about/company/ | 信頼の担保（許可番号・実績） | 電話・問い合わせ | — |
| /contact/ | 摩擦なく送信させる | フォーム送信 | 完了率 > 60% |
