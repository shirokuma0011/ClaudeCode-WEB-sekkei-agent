# 01. 現状分析

## 1. 総括

協進建設は、**コンテンツ資産（ZEH／BELS★★★★／高気密高断熱／地元八王子27年／施工例／自社ブランド）は十分に持っているのに、
サイトの構造がその価値を伝えられていない**状態です。

課題の本質は「デザインが古い」ことではなく、以下の3点に集約されます。

1. **URLとタイトルが機械可読でない** — 検索エンジンがページの主題を判定できない
2. **目的別導線がない** — 「家を建てたい人」「土地を探す人」「リフォームしたい人」が同じ入口に流し込まれている
3. **物件情報がページとして手作業運用** — 更新が重く、鮮度が命の不動産情報で致命的

---

## 2. 課題一覧（優先度順）

優先度は **影響度 × 修正容易性** で判定。`確` = 確定事実ベース、`推` = 推定、`検` = 要検証。

### 🔴 A-1 URLが内容を表していない 〔確〕

```
現状: /page1  /page6  /20190518144118  /20210709172902  /20230922152716
```

- 訪問者がURLを見ても何のページか分からない。SNS・メール・チラシで共有しづらい。
- 検索結果でのURL表示（パンくず）が意味をなさない。
- CMSの自動採番のため、**ページを作り直すとURLが変わりリンクが切れる**構造的リスク。
- `/forsale` `/shintiku` `/uriti` だけ手動命名されており、**設計思想が統一されていない**。
  さらに `shintiku`（新築）`uriti`（売地）はヘボン式でなく訓令式ローマ字で、可読性も低い。

→ **対策: 03章の新URL設計 ＋ 301リダイレクト表**

---

### 🔴 A-2 titleタグのキーワード詰め込みと重複 〔確〕

```
施工例 -外観・外構- | 協進住宅|協進建設|八王子市|不動産
PLAN集 | 協進住宅|協進建設|八王子市|不動産
会社概要 | 協進住宅|協進建設|八王子市|不動産
```

- 全ページに同じ4語の羅列が付与され、**タイトルの約7割が全ページ共通の文字列**。
- 検索結果ではタイトルが約30全角文字で切れるため、**ページ固有の情報が表示されない**危険。
- パイプ区切りのキーワード羅列はGoogleにタイトル書き換えの対象とされやすい。
- `Renovation`（`/20190622160130`）と `Renovation`（`/20210909110938`）が**完全同名**。
  `ステイブルハウス` と `ステイブルハウス2` も同様に、検索評価が分散（カニバリゼーション）。

→ **対策: 07章のtitle設計ルール ＋ 重複ページの統合**

---

### 🔴 A-3 物件情報がDB化されていない 〔推〕

- `/forsale`（物件情報）・`/shintiku`（新築分譲）・`/uriti`（売地）・`/20190518144118`（おすすめ物件）が
  **並列の静的ページ**として存在。物件1件ごとの独立ページがない。
- 結果として:
  - 物件単位で検索結果に出ない（「八王子市 ◯◯町 新築 戸建」で拾われない）
  - 構造化データ（`RealEstateListing`）を付けられない
  - 成約後の削除・価格改定が手作業で、**情報の鮮度が担保できない**
  - 「おすすめ物件」と「物件情報」の違いが利用者に分からない

→ **対策: 06章のデータモデル ＋ 物件詳細ページの新設**

---

### 🟠 A-4 事業とブランドの関係が不明瞭 〔確〕

「協進建設」「協進住宅」「ステイブルハウス」の3つの名称が並び、
title にも `協進住宅|協進建設` と両方が入っています。訪問者には以下が分かりません。

- 協進建設と協進住宅は別会社なのか（実際には統合済み）
- ステイブルハウスは商品名なのか、別ブランドなのか
- 注文住宅・分譲住宅のどちらを頼めるのか

→ **対策: 03章のブランド階層定義 ＋ 04章トップの事業区分ナビ**

---

### 🟠 A-5 目的別の導線設計がない 〔推〕

現状のページ群は「会社が持っている情報の一覧」であり、
「訪問者がやりたいこと」で整理されていません。

| 訪問者の目的 | 現状で見るべきページ | 問題 |
|---|---|---|
| 注文住宅を建てたい | ステイブルハウス / ステイブルハウス2 / PLAN集 / BELS評価 | 4ページに分散、順路がない |
| 建売を買いたい | 新築分譲住宅 / 物件情報 / おすすめ物件 | 3ページの違いが不明 |
| 土地を探したい | 売地・建築条件付売地 | 建築条件の意味が未説明 |
| リフォームしたい | Renovation ×2 / case | 同名ページが2つ |
| 会社を調べたい | 会社概要 | 実績・許可番号の網羅性 〔検〕 |

→ **対策: 03章の目的別ナビゲーション（`assets/diagrams/user-journey.svg`）**

---

### 🟠 A-6 強み（ZEH・BELS）が埋もれている 〔確〕

- ZEHビルダー登録、BELS★★★★、高気密高断熱（高性能グラスウール16K、ALCパワーボード）、
  日野の実邸で一次エネルギー消費量19%削減という**具体的な数値実績**を保有。
- しかしBELSは `/20210718095501` という日付URLの1ページに置かれ、
  トップからの導線・他ページからの内部リンクが弱いと推定される。
- 「夏涼しく冬暖かい」「光熱費」「補助金」は**検索需要が大きい**キーワード群。

→ **対策: 07章のキーワード設計 ＋ 04章の性能訴求セクション**

---

### 🟡 A-7 NAP（社名・住所・電話）の不整合 〔確／要確認〕

検索インデックス上、同社に関して異なる住所・電話番号が確認されました。

```
八王子市八木町5-4      / 042-624-7433 / FAX 042-623-2153
八王子市千人町2-18-5   / 042-661-8811 / FAX 042-673-5563
```

本社移転・支店・別法人のいずれかと思われますが、
**ローカルSEOではNAPの表記ゆれが評価を分散させます**。

→ **対策: 07章のNAP統一ルール ＋ Googleビジネスプロフィール整備**

---

### 🟡 A-8 メールアドレスがプロバイダドメイン 〔確〕

```
stable-house@an.wakwak.com
```

独自ドメイン `kyoushin-jt.co.jp` を保有しているのに、
連絡先が第三者プロバイダのドメインです。信頼性・到達率・継続性の面で不利です。

→ **対策: 06章 `info@kyoushin-jt.co.jp` への移行 ＋ SPF/DKIM/DMARC設定**

---

### 🟡 A-9 ページ更新が停滞している可能性 〔推／要検証〕

日付スラッグから推定される最終ページ作成は **2023年9月**（`/20230922152716`）。
2024年以降に作成されたページがインデックスで確認できませんでした。

- 不動産・住宅は「動いている会社か」が問い合わせの判断材料になります。
- 施工実績・現場レポート・スタッフブログ等の更新頻度が低いと、
  検索評価と信頼性の双方に影響します。

→ **対策: 09章の運用体制 ＋ 06章の更新しやすいCMS選定**
