## 1. この設計書の目的

八王子市を地盤とする **株式会社協進建設／協進住宅**（自社住宅ブランド「ステイブルハウス」）の
公式サイトを、「会社案内サイト」から **問い合わせを生む営業資産** へ転換するための設計書です。

新築・分譲・売地・リフォーム・駐車場・不動産仲介という複数事業を、
ユーザーの目的別導線に再編し、同社の実力（ZEHビルダー／BELS★★★★／高気密高断熱／地元密着）を
検索エンジンと見込み客の双方に正しく伝わる形に設計し直します。

### プロトタイプの検証結果

`tools/verify-prototype.js` を実行した結果、2ページとも以下を満たしています。

```
320 / 390 / 768 / 1024 / 1440px  横スクロール なし
html lang="ja" ／ h1 が1つ ／ 見出し階層の飛びなし ／ ID重複なし
全画像に alt と width/height 属性
viewport に user-scalable=no がない
title 30・33文字（32文字前後の基準内）／ description 86・92文字
タップターゲット 44px 以上（WCAG 2.5.5/2.5.8 の例外を適用して判定）
```

またカラーパレットのコントラスト比は、机上の設計ではなく実際に計算した値を
`05_デザインシステム.md` 2.2節に記載しています。

## 4. 現行サイト画像について（重要）

本設計書を作成した実行環境は **外部ネットワークが遮断**されており、
`www.kyoushin-jt.co.jp` を含む全ドメインへの直接アクセスができませんでした
（egress proxy による 403 CONNECT 拒否）。
そのため **現行サイトの画像そのものを取得して同梱することはできていません**。

代替として以下を用意しています。

1. `tools/fetch-site-assets.sh` — お手元のPCで実行すると、現行サイトを巡回して
   全画像を `assets/originals/` に保存し、一覧CSV（サイズ・寸法・alt有無）を生成します。
2. `assets/diagrams/` と `assets/mockups/` — 本設計書のために新規作成した図版・モックアップ画像。
3. `05_デザインシステム.md` の「画像仕様」章 — 撮影・書き出し・命名規則の設計。

詳細と、未検証項目を実機で埋める手順は `00_調査サマリと制約.md` と
`tools/audit-checklist.md` を参照してください。

## 5. 本設計書の位置づけ

- **確定事実** … 検索インデックス上で実在が確認できたURL・ページタイトル・企業情報。出典は 10章に明記。
- **推定** … 上記から論理的に導ける構造上の指摘（例: URL設計・タイトル設計）。「推定」と明記。
- **要検証** … 実機閲覧なしには断定できない項目（表示速度・レスポンシブ・フォーム等）。
  `tools/audit-checklist.md` に検証手順つきで列挙。

改善提案そのものは、確定事実と業界標準（Core Web Vitals / JIS X 8341-3 / 構造化データ仕様）に
基づいており、要検証項目の結果によって**優先順位**が変わることはあっても、**方向性**は変わりません。
