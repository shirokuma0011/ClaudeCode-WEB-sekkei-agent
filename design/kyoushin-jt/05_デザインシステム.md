# 05. デザインシステム

図版: `assets/diagrams/design-tokens.svg`
実装例: `prototype/index.html`（CSSカスタムプロパティとして実装済み）

---

## 1. デザインの方向性

| 軸 | 方針 | 理由 |
|---|---|---|
| 印象 | 誠実・堅実・あたたかい | 住宅は高額かつ長期の買い物。奇抜さより信頼が優先される |
| 主色 | **深緑** | 省エネ・断熱・自然素材という同社の強みと直結。競合の工務店に多い「青」「オレンジ」と差別化できる |
| 補色 | **テラコッタ（弁柄色）** | 木・土・レンガの温かみ。CTAとして深緑の上でも背景白でも埋もれない |
| 余白 | ゆったり | 情報密度を下げ、写真（＝商品）を主役にする |
| 写真 | 実邸中心・人の生活感 | CG・イメージ写真より、実際に建てた家が最大の説得材料 |

## 2. カラートークン

すべてのペアについて **WCAG 2.1 のコントラスト比を実測**し、表の右端に記載しています。

### 2.1 定義

```css
:root {
  /* Brand */
  --color-primary:        #1F4A3D;  /* 深緑 — 見出し・ナビ・リンク */
  --color-primary-dark:   #14332A;  /* ヘッダー・フッター背景 */
  --color-primary-light:  #E8F0EC;  /* 淡い面・セクション背景 */

  /* Accent (CTA) */
  --color-accent:         #A8481F;  /* CTAボタン背景 */
  --color-accent-hover:   #8A3A17;  /* CTAホバー・アクティブ */

  /* Text */
  --color-ink:            #1A1A1A;  /* 本文 */
  --color-ink-muted:      #5C5C5C;  /* 補足・キャプション */
  --color-ink-inverse:    #FFFFFF;

  /* Surface */
  --color-bg:             #FFFFFF;
  --color-bg-subtle:      #F7F5F1;  /* 温かみのあるオフホワイト */
  --color-border:         #E2DED7;  /* 装飾的な区切り線 */
  --color-border-strong:  #767268;  /* フォーム枠など機能的な境界 */

  /* Status（物件ステータス） */
  --color-status-sale:    #B03A2E;  /* 販売中 */
  --color-status-talk:    #8A5A12;  /* 商談中 */
  --color-status-sold:    #5B616E;  /* 成約済 */

  /* Semantic */
  --color-success:        #1E7A4B;
  --color-error:          #B3261E;
  --color-focus:          #0B5FFF;  /* フォーカスリング */
  --color-focus-inverse:  #FFB703;  /* 濃色背景上のフォーカスリング */
}
```

### 2.2 コントラスト検証結果（実測値）

| 用途 | 前景 / 背景 | 比 | 判定 |
|---|---|---|---|
| 本文 | `#1A1A1A` / `#FFFFFF` | **17.40** | AAA |
| 本文（淡背景） | `#1A1A1A` / `#F7F5F1` | **15.98** | AAA |
| 補足テキスト | `#5C5C5C` / `#FFFFFF` | **6.69** | AA |
| 見出し・リンク | `#1F4A3D` / `#FFFFFF` | **9.98** | AAA |
| ヘッダー文字 | `#FFFFFF` / `#14332A` | **13.67** | AAA |
| 淡緑面の文字 | `#1F4A3D` / `#E8F0EC` | **8.60** | AAA |
| **CTAボタン** | `#FFFFFF` / `#A8481F` | **5.81** | AA |
| CTAホバー | `#FFFFFF` / `#8A3A17` | **7.78** | AAA |
| ステータス 販売中 | `#FFFFFF` / `#B03A2E` | **6.02** | AA |
| ステータス 商談中 | `#FFFFFF` / `#8A5A12` | **5.91** | AA |
| ステータス 成約済 | `#FFFFFF` / `#5B616E` | **6.21** | AA |
| フォーム枠線 | `#767268` / `#FFFFFF` | **4.80** | AA（UI基準3:1を超過） |
| エラー文字 | `#B3261E` / `#FFFFFF` | **6.54** | AA |
| フォーカスリング | `#0B5FFF` / `#FFFFFF` | **5.13** | AA（UI基準3:1を超過） |

### 2.3 注意が必要な組み合わせ（設計上の制約）

| 組み合わせ | 比 | 対応 |
|---|---|---|
| フォーカス青 `#0B5FFF` / 深緑 `#1F4A3D` | **1.95 ✗** | **濃色背景上では `--color-focus-inverse` `#FFB703`（比5.71）を使う。** または白2px＋濃色2pxの二重リングにする |
| 区切り線 `#E2DED7` / 白 | 1.34 | **装飾専用**。フォーム枠・選択状態など意味を持つ境界には使わない（`--color-border-strong` を使用） |
| 明るいテラコッタ `#C4622D` / 白 | 4.09 | 通常サイズのテキストには**使用不可**。当初案から `#A8481F` へ変更済み |

> これらは机上の設計ではなく、`node` で実際にコントラスト比を計算した結果です。
> 実装時に色を変更する場合は、必ず再計算してください。

### 2.4 色だけに依存しない

物件ステータスは色とテキストの**両方**で示します（08章）。

```html
<span class="badge badge--sale">販売中</span>   <!-- 赤 + 文字 -->
<span class="badge badge--sold">成約済</span>   <!-- 灰 + 文字 -->
```

## 3. タイポグラフィ

### 3.1 フォントファミリー

```css
--font-sans: "Noto Sans JP", "Hiragino Kaku Gothic ProN", "Hiragino Sans",
             Meiryo, system-ui, sans-serif;
--font-num:  "Roboto", system-ui, sans-serif;  /* 価格・面積などの数字 */
```

- **Webフォントは最小限に**。Noto Sans JP を使う場合は `400` と `700` の2ウェイトのみ、
  `font-display: swap`、`unicode-range` によるサブセット化を必須とします。
  日本語Webフォントはフルセットで数MBあり、**LCPを直接悪化させます**。
- 予算・性能を優先するなら、**システムフォントのみ**の構成も十分に選択肢です。

### 3.2 スケール（モバイルファースト）

| トークン | SP | PC | 用途 | 行送り |
|---|---|---|---|---|
| `--fs-display` | 28px | 44px | トップのキャッチコピー | 1.3 |
| `--fs-h1` | 24px | 34px | ページ見出し | 1.35 |
| `--fs-h2` | 20px | 26px | セクション見出し | 1.4 |
| `--fs-h3` | 17px | 20px | 小見出し | 1.5 |
| `--fs-body` | **16px** | 16px | 本文（**最小値。これ未満にしない**） | 1.8 |
| `--fs-sm` | 14px | 14px | 補足・キャプション | 1.7 |
| `--fs-price` | 24px | 30px | 物件価格（`--font-num` / 700） | 1.2 |

- **日本語の本文行送りは 1.8** を基準に。欧文の1.5では詰まって読みづらくなります。
- 本文1行の文字数は **全角35〜45文字**（最大幅720px相当）に収めます。
- `font-size` に `px` を使いつつ、ルートに `rem` 換算を用意してユーザーの文字サイズ設定を尊重します。

### 3.3 日本語組版

```css
body {
  font-feature-settings: "palt" 1;   /* 約物の詰め */
  text-spacing-trim: space-first;     /* 対応ブラウザで行頭約物を詰める */
  line-break: strict;
  overflow-wrap: anywhere;
}
h1, h2, h3 { word-break: auto-phrase; }  /* 文節での改行（見出しのみ） */
```

## 6. コンポーネント仕様

### 6.1 ボタン

| 種別 | 背景 | 文字 | 用途 |
|---|---|---|---|
| Primary | `--color-accent` | 白 | 資料請求・送信など主要CTA（1画面に1つを原則） |
| Secondary | 透明 / 枠 `--color-primary` 2px | `--color-primary` | 来場予約など並列のCTA |
| Tertiary | なし | `--color-primary` 下線 | 「一覧を見る」等 |

```css
.btn {
  min-height: 48px;          /* タップターゲット。44px以上を確保 */
  padding: 12px 24px;
  border-radius: var(--radius-md);
  font-weight: 700;
  font-size: 16px;
}
.btn:focus-visible {
  outline: 3px solid var(--color-focus);
  outline-offset: 2px;
}
/* 濃色背景上 */
.on-dark .btn:focus-visible { outline-color: var(--color-focus-inverse); }
```

- **`outline: none` は禁止**。フォーカスが見えないとキーボード利用者が操作不能になります。
- 隣接するタップ要素の間隔は最低8px。

### 6.2 物件カード

```
┌─────────────────────┐
│ [img 4:3]  [badge]   │  badge は左上に絶対配置
├─────────────────────┤
│ 3,480万円             │  --fs-price / 700 / --color-ink
│ 八王子市八木町          │  --fs-body
│ 3LDK / 土地105m²      │  --fs-sm / --color-ink-muted
│ 西八王子駅 徒歩12分     │  --fs-sm / --color-ink-muted
└─────────────────────┘
```

- カード全体がリンク。`<a>` でラップせず、擬似要素でクリック領域を拡張（見出し内の `<a>` を基点に）。
- 画像は `width` / `height` 属性必須（CLS対策）＋ `aspect-ratio: 4/3` ＋ `object-fit: cover`。
- ホバー: `translateY(-2px)` ＋ `--shadow-md`。`prefers-reduced-motion` で無効化。

### 6.3 フォーム要素

```css
.field input, .field select, .field textarea {
  min-height: 48px;
  font-size: 16px;                 /* iOSの自動ズームを防ぐため16px未満にしない */
  border: 1px solid var(--color-border-strong);   /* 4.80:1 */
  border-radius: var(--radius-sm);
  padding: 12px;
}
.field input:focus-visible { outline: 3px solid var(--color-focus); outline-offset: 1px; }
.field--error input { border-color: var(--color-error); border-width: 2px; }
.field__error { color: var(--color-error); font-size: 14px; }  /* 色だけでなくテキストで示す */
```

- ラベルは `<label for>` で必ず紐付け。プレースホルダーをラベル代わりにしない。
- 必須は `必須` バッジ＋ `required` ＋ `aria-required="true"`。

### 6.4 ステータスバッジ

```css
.badge { padding:4px 10px; border-radius:var(--radius-full); font-size:13px; font-weight:700; color:#fff; }
.badge--sale { background: var(--color-status-sale); }
.badge--talk { background: var(--color-status-talk); }
.badge--sold { background: var(--color-status-sold); }
```

## 7. 画像仕様

現行サイトの画像を差し替え・再書き出しする際の基準です。

### 7.1 書き出し

| 用途 | 表示幅 | 書き出し | 形式 | 目標容量 |
|---|---|---|---|---|
| ヒーロー | 全幅 | 1920 / 1280 / 768 / 480px | AVIF → WebP → JPEG | ≤ 180KB（1920px時） |
| 物件カード | 380px | 760 / 380px | WebP → JPEG | ≤ 60KB |
| 事例メイン | 1200px | 2400 / 1200 / 600px | WebP → JPEG | ≤ 120KB |
| 間取り図 | 900px | 1800 / 900px | **WebP（可逆）または PNG** | ≤ 200KB |
| ロゴ・アイコン | — | — | **SVG** | ≤ 8KB |

```html
<picture>
  <source type="image/avif" srcset="hero-1920.avif 1920w, hero-1280.avif 1280w, hero-768.avif 768w" sizes="100vw">
  <source type="image/webp" srcset="hero-1920.webp 1920w, hero-1280.webp 1280w, hero-768.webp 768w" sizes="100vw">
  <img src="hero-1280.jpg" width="1920" height="1080" alt="八王子市に建てたステイブルハウスの外観"
       fetchpriority="high" decoding="async">
</picture>
```

- **ヒーロー画像に `loading="lazy"` を付けない**（LCPが遅延します）。
- ファーストビュー外の画像には `loading="lazy"` を必ず付ける。
- `width` / `height` 属性は**全画像に必須**（CLS対策）。
- 間取り図は文字が潰れるため、非可逆圧縮を強くかけない。

### 7.2 命名規則

```
{カテゴリ}-{識別子}-{連番}-{幅}.{拡張子}

property-1042-01-1200.webp     物件1042の1枚目
works-i-tei-exterior-01-1200.webp
plan-3ldk-a-madori-900.webp
common-logo.svg
```

### 7.3 alt属性

| 画像 | 悪い例 | 良い例 |
|---|---|---|
| 外観写真 | `alt="外観"` | `alt="八王子市八木町の新築分譲住宅の外観。白い外壁に木製の玄関ドア"` |
| 間取り図 | `alt="間取り"` | `alt="3LDKの間取り図。1階はLDK18畳と和室、2階は洋室3室"` |
| ロゴ | `alt="ロゴ"` | `alt="株式会社協進建設"` |
| 装飾的な背景 | `alt="装飾"` | `alt=""`（空にして支援技術から隠す） |

### 7.4 撮影ガイド（新規撮影時）

- 外観は**曇天より晴天の午前**、電線と電柱が入らない角度を探す。
- 内観は**広角24〜28mm**、三脚＋水平を厳守。傾いた柱は品質不安につながる。
- 生活感（家具・小物）を1〜2点入れる。完全な空室は寸法感が伝わらない。
- **人物を入れる場合は必ず肖像権の許諾書**を取得。お施主様の顔が写る場合は特に注意。
- 竣工時に **横位置・縦位置の両方**を撮る（SNSとモバイルで縦が必要になる）。

## 8. モーション

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

- アニメーションは `opacity` と `transform` のみ（レイアウトを再計算させない）。
- スクロール連動のフェードインは**0.2秒以内**。長いと「重いサイト」に感じられます。
- 自動再生カルーセルは**使わない**。操作を奪い、アクセシビリティを損ないます。
