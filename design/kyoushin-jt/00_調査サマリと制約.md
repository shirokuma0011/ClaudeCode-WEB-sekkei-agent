| 項目 | 内容 |

| 起点URL | `https://www.kyoushin-jt.co.jp/page1` |
| 使用手段 | 検索インデックス経由の情報収集（Web検索） |
| **使えなかった手段** | **HTTP直接取得・実機レンダリング・画像ダウンロード** |
| 制約の理由 | 実行環境の egress proxy が全外部ドメインへの CONNECT を 403 拒否（`example.com` を含む全ドメインで再現） |

この制約により、**HTMLソース・CSS・画像・表示速度・レスポンシブ挙動の直接確認はできていません**。
本設計書は「検索インデックスから確認できた事実」＋「Web標準・業界基準」に基づいて構成しています。

## 3. 推定（確定事実から論理的に導ける事項）

| # | 推定 | 根拠 |
|---|---|---|
| P-1 | CMSはJimdo系（または同種のノーコードCMS） | `/pageN` と `/YYYYMMDDhhmmss` という2種の自動生成スラッグの併存は同系CMSの典型 |
| P-2 | URLが手動設定されておらず、既定値のまま運用されている | `/page1` `/page6` と `/forsale` `/shintiku` `/uriti` が混在＝一部だけ手動設定 |
| P-3 | 全ページ共通のtitle接尾辞がテンプレートで自動付与されている | 全ページで `\| 協進住宅\|協進建設\|八王子市\|不動産` が一致 |
| P-4 | 物件情報が「ページ」として手作業更新されている | 物件がDB化されていれば `/property/{id}` 等の規則的URLになるはず |
| P-5 | ページの追加が場当たり的 | 「Renovation」「ステイブルハウス/2」の重複、日付スラッグの年が2018〜2023に散在 |

## 4. 要検証（実機確認が必要・`tools/audit-checklist.md` に手順）

以下は**断定していません**。検証結果により優先度が変動します。

- V-4 問い合わせフォームの有無・項目数・確認画面・送信到達性
- V-5 HTTPS常時化、`http→https` / `非www→www` の正規化
- V-6 `sitemap.xml` / `robots.txt` / `canonical` の設定
- V-7 構造化データ（JSON-LD）の実装有無
- V-8 GA4 / Search Console の導入状況
- V-9 会社所在地・電話番号の正（NAP統一のため）
- V-10 現行画像の実寸・容量・alt属性の付与状況

## 5. 制約が結論に与える影響

| 結論の種類 | 制約の影響 |
|---|---|
| IA・URL設計の再構築（03章） | **影響なし** — 確定事実のURL一覧のみで成立 |
| SEO設計（07章） | **影響なし** — title重複・URL不備は確定事実から導出済み |
| デザインシステム（05章） | 現行の配色・書体は不明のため、**新規提案**として構築 |
| 画面設計（04章） | 現行レイアウト不明のため、**あるべき姿から設計**（ゼロベース） |
| 性能改善の目標値（06章） | 現状値が不明なため、**業界標準の目標値**を設定。実測後に差分を確認 |
| 現行画像の同梱 | **達成できず** — `tools/fetch-site-assets.sh` で取得いただく設計に変更 |
