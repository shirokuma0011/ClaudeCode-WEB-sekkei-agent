### 共通ヘッダー

```
PC ┌────────────────────────────────────────────────────────────┐
   │ [LOGO 協進建設]   注文住宅 分譲・土地 リフォーム 施工事例 会社情報 │

   │ [LOGO]          [☎] [≡]    │  ← 高さ56px・スクロールで固定
   └────────────────────────────┘
   └── 画面下部に固定CTAバー: [☎ 電話] [資料請求]
```

- ロゴは必ず `/` へリンク。`alt="株式会社協進建設"`。
- 電話番号は**モバイルで `tel:` リンク**。受付時間を必ず併記（時間外の失望を防ぐ）。
- ハンバーガーメニューは `aria-expanded` / `aria-controls` を実装（08章）。
- SP の固定CTAバーは高さ56px。本文末尾に同じ高さのスペーサーを置き、コンテンツが隠れないようにする。

## 1. トップページ

### 構成（上から）

| # | セクション | 目的 | 要素 |
|---|---|---|---|
| 1 | ヒーロー | 3秒で「誰の何を解決する会社か」を伝える | 施工写真（実邸）／キャッチ／サブコピー／CTA 2つ |
| 2 | 目的別ナビ | 訪問者を最短で振り分ける | 4カード（注文住宅／分譲・土地／リフォーム／施工事例） |
| 3 | 性能訴求 | 差別化要素の提示 | ZEH・BELS★★★★・高気密高断熱の3指標＋数値 |
| 4 | 新着物件 | 鮮度の証明 | 物件カード3〜4件（横スクロール可）＋一覧へ |
| 5 | 施工事例 | 実力の証明 | 事例カード3件＋一覧へ |
| 6 | 選ばれる理由 | 信頼の積み上げ | 創業1998年／八王子密着／一貫対応／協力業者研修 |
| 7 | 家づくりの流れ | 不安の解消 | 6ステップの図 |
| 8 | お知らせ | 動いている会社の証明 | 最新3件 |
| 9 | CTA | 行動喚起 | 資料請求／来場予約／電話 |

### ヒーロー詳細

```
┌──────────────────────────────────────────────────────┐
│  [背景: 実際に建てた家の写真（人物や生活感があるもの）]      │
│                                                       │
│   次世代まで住み継ぐ家を。                              │  ← H1
│   八王子で27年、土地探しから建てた後まで。               │  ← サブコピー
│                                                       │
│   [ ZEHビルダー ] [ BELS ★★★★ ] [ 創業1998年 ]        │  ← 信頼バッジ
│                                                       │
│   [ 資料請求（無料） ]  [ 来場・相談を予約 ]             │  ← CTA 2つ
└──────────────────────────────────────────────────────┘
```

**設計上の意思決定:**

- **H1は1つだけ**、「次世代まで住み継ぐ家を」＋地域名を含める。
  現行のtitleのようなキーワード羅列は使わない（07章）。
- CTAは**必ず2つ**。「資料請求（低ハードル）」を第一、「来場予約（高ハードル）」を第二に。
  1つだけだと、まだ検討初期の訪問者を取りこぼす。
- ヒーロー画像は **LCP要素**になるため、`fetchpriority="high"` ＋ `<picture>` でAVIF/WebP配信、
  遅延読み込みは**かけない**（06章の性能予算）。
- 画像にはテキストを焼き込まない（レスポンシブと多言語化、そして可読性のため）。

### 性能訴求セクション（課題A-6への対応）

```
┌───────────────┬───────────────┬───────────────┐
│  UA値 0.XX     │  C値 X.X       │ 一次エネ -19%  │
│  W/(m²·K)      │  cm²/m²        │  （日野の実邸） │
│  [断熱の仕組み] │  [気密の測定]   │  [BELS評価とは] │
└───────────────┴───────────────┴───────────────┘
  ↓
「冬の朝、廊下が寒くない家」— 数値の意味を1文で翻訳する
  ↓
[ 性能について詳しく ]  → /custom-home/performance/
```

> **数値は必ず実測値を入れてください。** UA値・C値は自社の実績値を、
> 一次エネルギー削減率19%は既に公表済みの実績です。
> 「高気密高断熱」という**言葉だけでは競合と差がつきません**。数字が差になります。

## 3. 物件一覧 `/property/`

```
┌─ H1: 八王子市の新築分譲住宅・売地 ──────────────────────┐
├─ 絞込みバー ──────────────────────────────────────────┤
│  [種別: 新築分譲/売地/建築条件付/駐車場]                 │
│  [エリア: 八王子市▼（町名まで）/日野/多摩/あきる野]       │
│  [価格: 〜3000万 / 3000-4000 / 4000-5000 / 5000万〜]     │
│  [間取り: 2LDK/3LDK/4LDK以上]  [ 販売中のみ ☑ ]          │
├─ 並び替え: 新着順 / 価格が安い順 / 価格が高い順 ──────────┤
├─ 物件カード グリッド（PC3列 / TB2列 / SP1列）────────────┤
│  ┌────────────┐                                        │
│  │ [写真 4:3]  │  ← object-fit: cover、寸法属性必須      │
│  │ 🔴販売中     │  ← ステータスバッジ                     │
│  │ 3,480万円    │  ← 価格を最も大きく                     │
│  │ 八王子市八木町 / 3LDK / 土地105m² / 建物98m²          │
│  │ JR中央線「西八王子」駅 徒歩12分                        │
│  └────────────┘                                        │
├─ ページネーション ────────────────────────────────────┤
└─ 「ご希望の物件が見つかりませんか？」→ 希望条件登録 ──────┘
```

**設計上の意思決定:**

- **価格を最も大きく**表示。不動産探しの第一判断軸であり、隠すと離脱します。
- ステータスバッジ（🔴販売中／🟡商談中／⚫成約済）を必須。
  **成約済も残して後方に配置**します。削除すると「実績がない会社」に見え、
  残せば「売れている会社」の証明になります（成約済は `noindex` ＋価格非表示）。
- 絞込みはURLクエリに反映（`/property/?type=new-house&area=hachioji`）し、
  共有・ブックマークを可能に。ただし**クエリ付きURLは `canonical` を一覧トップに向ける**（07章）。
- カードは**リンク領域を全体**に。タップターゲット44×44px以上。
- 「見つからない場合」の受け皿を必ず置く。ここが隠れたCV源になります。

- 物件概要テーブルは**CMS側で入力必須**にし、法定表示の漏れを構造的に防ぎます。
- 写真スライダーは矢印キー操作とスワイプの両対応、各画像に説明的な `alt`。

```

### 詳細
```
H1: 八王子市I様邸 — 共働き夫婦の「帰ってくるのが楽しい家」
├─ 外観 大判写真
├─ DATA: 所在地 / 竣工 / 構造 / 延床 / 家族構成 / 工期 / 【価格帯】
├─ お施主様の要望 → 提案 → 結果（ストーリー3段構成）

├─ 使用した性能仕様（UA値・断熱材・サッシ）→ /custom-home/performance/
├─ お客様の声（あれば）
└─ CTA: 「こんな家を建てたい」→ 資料請求

> **価格帯の明示を強く推奨します。** 「2,500〜3,000万円」程度のレンジ表記で構いません。
> 価格が分からない事例は、検討者にとって参考になりません。
> 逆に価格があると、予算の合う訪問者の問い合わせ確度が大きく上がります。

## 7. 問い合わせ `/contact/`

### 入口の分岐（1画面目）
```
何についてのご相談ですか？
┌─────────────┐┌─────────────┐┌─────────────┐
│ 📄 資料請求   ││ 🏠 来場・相談 ││ 🔧 リフォーム │
│ まずは情報が   ││ 直接話したい  ││ 相談したい    │
│ ほしい方       ││              ││              │
└─────────────┘└─────────────┘└─────────────┘
        ┌─────────────┐┌─────────────┐
        │ 🏘 物件について││ ✉ その他      │
        └─────────────┘└─────────────┘
      または ☎ 042-XXX-XXXX（9:00-18:00 / 定休日◯曜）
```

### フォーム設計原則

| 原則 | 内容 |
|---|---|
| **項目を絞る** | 必須は「お名前・連絡先（メール**または**電話）・ご相談内容」の3つまで |
| 任意は明示 | 住所・希望エリア・予算・建築時期は**すべて任意**とラベル表示 |
| 1カラム | 横並び入力にしない（モバイルでの誤タップと視線移動を防ぐ） |
| 入力支援 | `autocomplete` 属性、`inputmode="tel"` / `type="email"` を適切に指定 |
| リアルタイム検証 | エラーは入力欄の直下にテキストで。色だけで示さない（08章） |
| 確認画面 | 省略可。ただし送信前に内容サマリを表示 |
| 完了後 | 完了ページへ遷移（GA4のCV計測のため）＋ 自動返信メール＋ 対応時間の目安を明記 |
| スパム対策 | reCAPTCHA v3（不可視）＋ ハニーポット。**画像認証は使わない**（離脱と非アクセシブル） |
| 同意 | プライバシーポリシーへのリンク＋同意チェックを必須 |

> **項目数とCVRは強く反比例します。** 予算・希望時期・土地の有無などは
> 営業上ほしくなりますが、**最初の接点で聞くほど送信されなくなります**。
> それらは自動返信メールや折り返しの電話で聞く設計にしてください。

## 9. エラー・空状態

| 状態 | 設計 |
|---|---|
| 404 | 「お探しのページは移動しました」＋ 検索窓 ＋ 主要導線4つ。旧URLからの流入を受け止める |
| 物件0件 | 「条件に合う物件がありません」＋ 条件の一部解除を提案 ＋ 希望条件登録フォーム |
| フォーム送信失敗 | 入力内容を保持したままエラー表示。電話番号を代替手段として提示 |
| 画像読込失敗 | `alt` テキストが表示される設計（`alt=""` を安易に使わない） |
